## 1. Executive Summary & Strategic Role in AcuDiag

In home appliance maintenance, **voice is the universal frontline interface**. Indian consumers facing sudden washing machine breakdowns or refrigerator failures do not navigate multi-page web forms—they want to speak naturally in their native language (Hindi, Kannada, Tamil, Hinglish) and receive immediate, empathetic, and authoritative diagnosis.

**AcuDiag deploys Gnani as the Voice Interaction Triad**:
1. **Multilingual Diagnostic Intake**: Ingests customer voice complaints across 10 Indian languages via Gnani Prisma v2.5 (`hi-IN`, `kn-IN`, `ta-IN`, `te-IN`, `hi-en`), transcribing technical symptoms into normalized diagnostic tokens.
2. **Interactive Audio Testing Guidance**: Guides the homeowner through physical microphone positioning (holding the phone 5 cm from the drum or motor) using natural conversational prompts generated by Gnani Timbre v2.5.
3. **Escrow & Logistics Dispatches**: Verbally explains the Pine Labs escrow pre-authorization and Delhivery spare part tracking number in the user's preferred native language.
4. **Adversarial Noise & Code-Switching Handling**: Leverages Gnani's native vocabulary biasing and Hinglish normalization to handle noisy environments and mixed English-Hindi speech without hallucination.

## 3. Speech-to-Text (STT) Specifications: Gnani Prisma v2.5

### 3.1. REST Transcription Endpoint
- **URL**: `POST https://api.vachana.ai/stt/v3`
- **Headers**:
  ```http
  Content-Type: multipart/form-data
  X-API-Key-ID: {{GNANI_API_KEY}}
  ```
- **Multipart Form Parameters**:
  | Parameter | Type | Required | Description |
  | :--- | :--- | :--- | :--- |
  | `audio_file` | File / Binary | Yes | Audio recording (WAV, MP3, FLAC, OGG, WebM). |
  | `language_code` | String | Yes | ISO locale code (`hi-IN`, `en-IN`, `kn-IN`, `ta-IN`, `te-IN`, `hi-en`). |
  | `format` | String | Yes | Set to `transcribe`. |
  | `itn_native_numerals` | Boolean | No | `true` converts spelled-out numbers into digits. |
  | `enable_substitution` | Boolean | No | `true` activates regex substitution map. |
  | `substitution_map` | JSON String | No | Custom pattern-replacement rules for domain terms. |
  | `bias_list` | JSON Array | No | Priority word list boosted in beam search decoding. |
  | `bias_score` | Integer | No | Confidence multiplier (typically `1` to `5`). |

### 3.2. AcuDiag Domain Vocabulary Biasing
To prevent mis-transcriptions of specialized engineering and financial terms, AcuDiag registers:
```json
{
  "bias_list": [
    "AcuDiag",
    "washing machine",
    "refrigerator",
    "drain pump",
    "drum bearing",
    "compressor",
    "capacitor",
    "Pine Labs",
    "escrow",
    "Delhivery",
    "waybill",
    "decibel",
    "Hertz",
    "pre-auth"
  ],
  "bias_score": 3
}
```

### 3.3. Response Schema
```json
{
  "success": true,
  "request_id": "req_acudiag_stt_98214",
  "timestamp": "20260930_164800.123",
  "transcript": "मेरी गोदरेज वॉशिंग मशीन स्पिन साइकिल में बहुत तेज़ खड़-खड़ आवाज़ कर रही है।"
}
```

### 3.4. Real-time WebSocket Protocol
- **Endpoint**: `wss://api.vachana.ai/stt/v3/realtime`
- Transmits raw 16-bit linear PCM audio in 100ms chunks (16kHz mono).
- Emits interim hypothesis tokens and finalized sentence boundaries.

## 4. Text-to-Speech (TTS) Specifications: Gnani Timbre v2.5

### 4.1. REST Inference Endpoint
- **URL**: `POST https://api.vachana.ai/api/v1/tts/inference`
- **Headers**:
  ```http
  Content-Type: application/json
  X-API-Key-ID: {{GNANI_API_KEY}}
  ```

```json

  "text": "नमस्ते श्री जसवंत। आपकी वॉशिंग मशीन का ड्रेन पंप खराब पाया गया है। नया ओईएम पार्ट डेलिवरी द्वारा कल सुबह 11 बजे डिलीवर होगा। पाइन लैब्स एस्क्रो में ₹1,200 सुरक्षित हो चुके हैं।",

  "language": "hi-IN",
  "speed": 1.0,
  "audio_config": {
    "sample_rate": 24000,
    "num_channels": 1,
    "sample_width": 2,
    "encoding": "linear_pcm",
    "container": "wav"
  }
}
```

3. **Fulfillment Phase**: Delhivery manifests forward pickup from Godrej Hub $\rightarrow$ Pine Labs captures pre-auth parts escrow hold $\rightarrow$ Gnani speaks tracking ETA to homeowner.
4. **Resolution Phase**: Post-repair acoustic verification passes ($LRT > 4.5$) $\rightarrow$ Pine Labs releases escrow payout to technician $\rightarrow$ Delhivery schedules reverse pickup for scrap analysis $\rightarrow$ Gnani issues verbal thank-you receipt.
