# AcuDiag • Additional Information & Research Archive

This directory organizes supplementary information, raw meeting transcripts, visual screenshots, and exploratory research probes created during development for **The Ken Case-Build 2026 (Round 3 Build Track)**.

---

## 📁 Directory Structure

### 1. `meeting_transcripts/`
- **`FIREFLIES_QA_SESSION.txt`** & **`fireflies_raw.json`**: Complete Q&A and raw transcript from jury and mentor briefing sessions.
- **`FULL_FIREFLIES_INPUT.txt`**: Consolidated transcript log.
- **`LIVE_PINE_LABS_DEMO_PART2.txt`** & **`LIVE_PINE_LABS_DEMO_TRANSCRIPT.txt`**: Verbatim transcript from Pine Labs AgenticOrg API walk-through.

### 2. `visual_artifacts/`
- **`acudiag_*`**: UI screenshots of AgenticOrg dashboards, tool registries, and execution dockets.
- **`otter_screenshot_*`**: Screen captures from technical briefing sessions.
- **`prakhar_screen_*` / `prakhar_mcp_screen_*`**: Screen captures of API architecture and MCP interface demonstrations.

### 3. `research_probes/`
- Ad-hoc scripts used during initial reverse-engineering, schema discovery, Otter/Fireflies parsing, and tool registry probes (`probe_*`, `check_*`, `inspect_*`).
- Pre-production test runners and exploratory AgenticOrg integration harnesses.
